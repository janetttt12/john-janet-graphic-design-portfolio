DEPLOY

2. Choose Add New → Project.
3. Import a Git repository (recommended) or deploy using Vercel CLI.
4. If using GitHub: create a new repository, upload the contents of this folder (index.html and assets/), then import that repository in Vercel.
5. Keep the settings above and click Deploy.
